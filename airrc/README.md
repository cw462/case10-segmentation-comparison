## 评估口径与结果解读

- GT 标签值 1/2/3/4 分别对应气道腔、气道壁、肺动脉、肺静脉；预测按 NRRD 的 Segment Name、Layer 和 LabelValue 读取独立图层。肺没有对应 GT，因此没有肺评分。
- 保持 GT 的 1 mm 各向同性网格不变，按物理坐标将预测最近邻重采样到 GT 网格，网格外填 0；没有平滑、碎片清理或人工修正。形状、affine、变换、类别映射和输入 SHA256 见[输入审计](results/input_audit.json)。
- Dice、Precision、Recall、IoU 按逐类 TP/FP/FN 计算。clDice 使用 Lee 三维骨架；气道壁是壳状结构，其 clDice 需谨慎解释。
- NSD 是面积加权表面 Dice，容差 1 mm。HD95 为两个方向各自面积加权 95% 分位距离的较大值。本次使用 surface-distance 0.1 的表面元和面积，采用精确 cKDTree 最近邻降低内存；原评估脚本包含与稠密实现的小体数据等价检查。
- 三例中血管指标总体较高，动静脉平均 clDice 均超过 96%；这说明骨架覆盖较好，不能证明所有分支及动静脉分类均正确。
- 气道腔平均精确率 90.04%、召回率 81.24%，提示相对参考标签漏分较多；case02 气道腔 clDice 为 72.76%。气道壁为主要短板，case02 精确率为 48.84%，约一半预测气道壁体素与参考气道壁重合。
- 气道壁 NSD 为 96.76 ± 1.88%，但 Dice 为 65.38 ± 8.47%；1 mm 容差对薄壁结构较宽松。HD95 为 1 mm 也不表示所有边界误差均不超过 1 mm。
- 仅三例描述性评估，没有逐层人工影像复核，与模型训练集的独立性尚未核实。这组预测重采样至固定的 GT 网格，Case10 与 PARSE2022 的数据及协议不同，不合并排名。

## 来源、代码与发布校验

归档原始 Excel、逐例 JSON/CSV、汇总 JSON、12 个逐病例逐类别 JSON、结果解读、环境和输入审计；这些结果文件与本地原件逐字节一致。另从完整精度汇总 JSON 导出汇总 CSV。截图中可见的 112 个数值、三例均值和样本标准差、逐例体素指标，以及 Excel/CSV/JSON 一致性均已核对。校验记录见 [publication_manifest.json](publication_manifest.json)。

[原评估脚本](code/evaluate_airrc_three.py)、[汇总脚本](code/summarize_airrc_three.py)及[指标实现](code/vesmamba_metrics.py)保留原评分逻辑，仅将本机数据和代码路径替换为通用路径，并移除本机专用依赖搜索路径；surface-distance 需由使用者安装。原环境版本见 [environment.json](results/environment.json)。脚本含本次三个病例和文件布局的假定，不能直接用于其他数据集。

通用输入目录为 `data/airrc/原始CT与totalsegmental/<case>/`（CT 与 segmentation.seg.nrrd）、`data/airrc/原始CT与标准mask/<case>/分割mask/<case>.nii.gz`，以及 data/airrc/原始CT与标准mask/病例对应表.csv。汇总脚本额外用 `data/airrc_original_predictions/<case>/segmentation.seg.nrrd` 核对原交付文件哈希。脚本生成的本地输出仍为 data/airrc/分割效果评估_20261022/；本仓库的 airrc/results/ 是归档副本。

发布内容为指标、审计和代码；病例 CT、GT、预测影像保留在本地。SHA256 可用于追溯本地原件，不表示原始影像已上传。原始文件与发布副本的哈希及路径替换记录见发布清单。
